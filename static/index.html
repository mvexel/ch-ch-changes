OSM Changeset API

Query OpenStreetMap changeset data via REST API or direct DuckDB access to parquet files.

This service is useful if you want to retrieve metadata for a non-trivial subset of OSM changeset metadata. OSM lets you retrieve up to 100 at the time using the OSM API (docs). This service lets you query by minute, hour, day and even day ranges.

Data Updates

Changeset data is updated weekly using the canonical changeset archive file OSM makes available. Check the /meta/coverage endpoint for the latest available date.

API Endpoints

GET /health - Health check

curl https://DOMAIN/health

GET /changeset/{id}.json - Single changeset

curl https://DOMAIN/changeset/1.json

GET /changesets/day/{YYYY-MM-DD} - All changesets on a date

curl https://DOMAIN/changesets/day/20240115

GET /changesets/day/{YYYYMMDD}/hour/{HH}/[minute/{MM}] - All changesets on a date and time.

curl https://DOMAIN/changesets/day/20240115/hour/23/minute/59

GET /changesets/from/{start}/to/{end} - Date range (only handles entire days) response can be huge!

curl https://DOMAIN/changesets/from/20240101/to/20240131

GET /meta/tip - Latest changeset ID

curl https://DOMAIN/meta/tip

GET /meta/coverage - Available date range

curl https://DOMAIN/meta/coverage

Direct DuckDB Access

Query parquet files directly. The parquet data is partitioned by year and month.

Browse parquet files →

# Example: Count changesets in 2024
duckdb -c "
  SELECT COUNT(*)
  FROM read_parquet('https://DOMAIN/data/changesets_2024_*.parquet')
"
# Example: Top contributors
duckdb -c "
  SELECT user, COUNT(*) as changesets
  FROM read_parquet('https://DOMAIN/data/changesets_2024_*.parquet')
  GROUP BY user
  ORDER BY changesets DESC
  LIMIT 10
"

Python Example

import duckdb

# Query remote parquet
result = duckdb.sql("""
    SELECT
        DATE_TRUNC('day', created_at) as day,
        COUNT(*) as changesets
    FROM read_parquet('https://DOMAIN/data/changesets_2024_*.parquet')
    GROUP BY day
    ORDER BY day
""").df()

print(result)

Data Schema

Each changeset includes:

  • id - Changeset ID (integer)
  • created_at - Timestamp
  • closed_at - Timestamp (if closed)
  • open - Boolean
  • user - Username (string)
  • uid - User ID (integer)
  • num_changes - Number of edits
  • comments_count - Number of comments
  • bbox - Bounding box (struct)
  • tags - Key-value tags (map)

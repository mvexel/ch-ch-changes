OSM Bulk Changeset API

Query OpenStreetMap changeset metadata in bulk.

This service is useful if you want to retrieve metadata for a non-trivial subset of OSM changeset metadata. OSM lets you retrieve up to 100 at the time using the OSM API (docs). This service lets you query by minute, hour, day and even day ranges. Additionally, you can filter by user ID, bounding box, and tags.

About Changesets

Each time an OpenStreetMap contributor uploads their edits, a changeset gets created. A changeset has two components: metadata and map changes. The metadata part, which is what this service provides, tells you useful things about the changeset: when it was opened, closed, by whom, which editor was used, and some more useful information about the context of the changes made to the map. The map changes is the information about the actual edits the contributor made to OSM. This can be any combination of adding new features, changing existing ones, or deleting features. There are some links below if you want to learn more.

Data Updates

Changeset data is updated weekly using the canonical changeset archive file OSM makes available. Check the /meta/coverage endpoint for the latest available date.

API Endpoints

GET /health - Health check

curl https://DOMAIN/health

GET /changeset/{id} - Single changeset

# XML format (default)
curl https://DOMAIN/changeset/1

# JSON format (using extension)
curl https://DOMAIN/changeset/1.json

# JSON format (using query param)
curl https://DOMAIN/changeset/1?format=json

GET /changesets/day/{YYYYMMDD} - All changesets on a date

# XML format (default)
curl https://DOMAIN/changesets/day/20240115

# JSON format
curl https://DOMAIN/changesets/day/20240115.json

# JSONL format (one changeset per line, useful for large results)
curl https://DOMAIN/changesets/day/20240115.jsonl

GET /changesets/day/{YYYYMMDD}/hour/{HH} - All changesets in a specific hour

curl https://DOMAIN/changesets/day/20240115/hour/23.json

GET /changesets/day/{YYYYMMDD}/hour/{HH}/minute/{MM} - All changesets in a specific minute

curl https://DOMAIN/changesets/day/20240115/hour/23/minute/59.json

GET /changesets/date/from/{start}/to/{end} - Date range (entire days) response can be huge!

curl https://DOMAIN/changesets/date/from/20240101/to/20240131.json

GET /changesets/id/from/{start}/to/{end} - Changeset ID range response can be huge!

curl https://DOMAIN/changesets/id/from/1/to/100.json

GET /meta/tip - Latest changeset ID

curl https://DOMAIN/meta/tip

GET /meta/coverage - Available date range

curl https://DOMAIN/meta/coverage

Format Options

All endpoints support multiple output formats:

  • xml - OSM XML format (default)
  • json - JSON format
  • jsonl - JSON Lines format (one changeset per line, for batch endpoints only)

Specify format using file extension (e.g., .json) or query parameter (e.g., ?format=json)

Query Parameters

Batch endpoints (day/hour/minute/range) support filtering and pagination:

  • user - Filter by username (e.g., ?user=alice)
  • uid - Filter by user ID (e.g., ?uid=123)
  • open - Filter by open/closed status (e.g., ?open=true)
  • limit - Limit number of results (e.g., ?limit=100)
  • offset - Offset for pagination (e.g., ?offset=100)
# Example: Get first 50 changesets by user 'alice' on a specific day
curl "https://DOMAIN/changesets/day/20240115.json?user=alice&limit=50"

Remember that OSM usernames are case-sensitive, so alice is probably not the same mapper as Alice.

Data Schema

Each changeset includes:

  • id - Changeset ID (integer)
  • created_at - Timestamp
  • closed_at - Timestamp (if closed)
  • open - Boolean
  • user - Username (string)
  • uid - User ID (integer)
  • num_changes - Number of edits
  • comments_count - Number of comments
  • bbox - Bounding box (struct)
  • tags - Key-value tags (map)

Rate Limits

None currently. This service offered as-is with no uptime / availability guarantees.

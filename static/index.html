OSM Changeset API

Query OpenStreetMap changeset data via REST API or direct DuckDB access to parquet files.

API Endpoints

GET /health - Health check

curl https://DOMAIN/health

GET /changeset/{id}.json - Single changeset

curl https://DOMAIN/changeset/1.json

GET /changesets/day/{YYYY-MM-DD} - All changesets on a date

curl https://DOMAIN/changesets/day/2024-01-15

GET /changesets/from/{start}/to/{end} - Date range

curl https://DOMAIN/changesets/from/2024-01-01/to/2024-01-31

GET /meta/tip - Latest changeset ID

curl https://DOMAIN/meta/tip

GET /meta/coverage - Available date range

curl https://DOMAIN/meta/coverage

Direct DuckDB Access

Query parquet files directly for analytics without API limits:

Browse parquet files →

# Example: Count changesets in 2024
duckdb -c "
  SELECT COUNT(*)
  FROM read_parquet('https://DOMAIN/data/changesets_2024_*.parquet')
"
# Example: Top contributors
duckdb -c "
  SELECT user, COUNT(*) as changesets
  FROM read_parquet('https://DOMAIN/data/changesets_2024_*.parquet')
  GROUP BY user
  ORDER BY changesets DESC
  LIMIT 10
"

Python Example

import duckdb

# Query remote parquet
result = duckdb.sql("""
    SELECT
        DATE_TRUNC('day', created_at) as day,
        COUNT(*) as changesets
    FROM read_parquet('https://DOMAIN/data/changesets_2024_*.parquet')
    GROUP BY day
    ORDER BY day
""").df()

print(result)

Data Schema

Each changeset includes:

  • id - Changeset ID (integer)
  • created_at - Timestamp
  • closed_at - Timestamp (if closed)
  • open - Boolean
  • user - Username (string)
  • uid - User ID (integer)
  • num_changes - Number of edits
  • comments_count - Number of comments
  • bbox - Bounding box (struct)
  • tags - Key-value tags (map)

Rate Limits

API: Standard web server limits apply

DuckDB: No rate limits, query directly from parquet files
